# KiLibEdit

KiCad 10 の `.kicad_sym` を表形式で一括編集するWindows向けデスクトップツールです。Python 3.10以降とTkinterを使用し、追加パッケージは不要です。

## 起動

exe版は `dist\main.dist\KiLibEdit.exe` をダブルクリックして起動します。Pythonのインストールは不要です。配布時は `main.dist` フォルダー全体を渡してください。

`Start.bat` をダブルクリック、または `python main.py` を実行します。`python main.py "ライブラリ.kicad_sym"` でファイルを指定できます。

## exeのビルド（Nuitka）

`Build.bat` を実行すると、専用の`.venv`へ`requirements-build.txt`のビルドツールをインストールし、`dist\main.dist\KiLibEdit.exe`を生成します。ビルドには64bit版Python 3.10とインターネット接続が必要です。初回はNuitkaが必要なコンパイラなどをダウンロードします。

standaloneモードでPythonとTcl/Tkを `dist\main.dist` に同梱し、コンソールウィンドウを表示しない設定です。exeと同じフォルダーのDLLやデータも起動に必要です。`dist\main.build` はビルド中間生成物で、配布には不要です。以前のonefileビルドによる `dist\KiLibEdit.exe` が残っている場合は、更新日時と出力先を確認してください。

Windows 64bit向けです。ビルド環境ではWindows Runtime DLLの同梱に関するNuitkaの警告が出ています。配布先によってはMicrosoft Visual C++ 2015–2022再頒布可能パッケージ（x64）が必要です。

## 操作

1. 「開く」でライブラリを選択します。
2. セルをダブルクリックして編集します。Enterまたはフォーカス移動で確定、Escでキャンセルします。
3. Ctrl・Shiftで複数行を選択し、対象列のセルをクリックして「一括設定」を使います。空文字を設定すると値を空にします。
4. 「列を追加」で独自プロパティを追加できます。値を設定したシンボルにのみプロパティを書き込みます。
5. 「保存」または「名前を付けて保存」で書き込みます。

検索は全列の部分一致です。見出しクリックでソートできます。変更行は黄色です。SymbolとExtendsは読み取り専用です。継承元のプロパティ値は展開せず、そのシンボルに直接記述された値を表示します。継承シンボルの空欄を編集するとローカルのプロパティを追加します。

コピーは、選択行を表示順で、クリックした列から右端までタブ区切りで取得します。Excelなどからコピーした矩形範囲は、最上部の選択行・クリックした列を起点に、現在の表示順で貼り付けます。ヘッダー行は含めないでください。範囲が表を超える場合は全体を拒否します。貼り付けは1回の「元に戻す」で取り消せます。

ショートカット: Ctrl+O 開く、Ctrl+S 保存、Ctrl+Z 元に戻す、Ctrl+Y やり直す、Ctrl+C コピー、Ctrl+V 貼り付け。セル入力中は入力欄の通常操作を優先します。

## 保存と対応範囲

- S式を解析し、編集したプロパティ値の位置だけを置換します。ピン、図形、単位、埋め込みデータ、未対応トークンや既存の表示設定を保持します。
- 新規プロパティは非表示で追加します。編集時はgeneratorを`kilibedit`へ変更し、versionは維持します。
- 上書き先の元ファイルは日時付き`.bak`へ保存します。一時ファイルの書き込み後に置換し、読み込み後の外部変更を検出した場合は上書きしません。
- シンボルの追加・削除・名前変更、プロパティ自体の削除、図形・ピン編集、旧`.lib`形式、複数ライブラリの同時編集は対象外です。
- KiCadと同じライブラリを同時編集しないでください。書き込み可能なコピーでの利用を推奨します。

形式の参照: [KiCad公式シンボルライブラリ仕様](https://dev-docs.kicad.org/en/file-formats/sexpr-symbol-lib/)。KiCad固有APIには依存しません。

## 検証

`python -m unittest -v` で、未編集時の完全一致、特殊文字、独自プロパティ追加、図形保持、不正入力、バックアップと競合検出を検証できます。

KiCad 10.0付属のDeviceライブラリ537シンボルのGUI読み込み、privateプロパティ保持、および独自プロパティ追加後のKiCad 10 CLIによるAmmeter_ACのSVG出力を確認済みです。
